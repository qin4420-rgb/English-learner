# English Room

English Room 是一个私人英语学习网站，集中提供新概念英语精听、文章精读、FSRS 单词复习、学习进度、学习工具目录、资料蒸馏和个人笔记。

## 给网站使用者

日常维护不需要改代码：

1. 打开网站并登录。
2. 在“维护中心”提交网页链接或上传 PDF、Markdown、TXT、HTML 和字幕文件。
3. 网站将资料整理成 Markdown；连接个人版 OneDrive 后同步到应用专用文件夹。
4. 在“文章精读”使用目录、阅读进度、双语模式和随读查词。
5. 在“单词本”导入外部词表，并按 FSRS 安排复习。
6. 定期点击“导出索引备份”，保留一份 JSON 数据索引。

页面结构调整、批量迁移、增加单词本等功能时，不需要自己看代码。直接在 Codex 桌面客户端打开本项目，用中文说明需要修改的内容即可。

## 资源放置建议

- GitHub：只放网站源代码、数据库结构、说明文档和公共静态资源，不放 API 密钥、令牌、私人文章、笔记或学习记录。
- OneDrive：个人资料的主要文件中心，保存整理后的 Markdown；网站仅申请应用专用文件夹权限。
- 网站数据库：保存资源索引、课程配置、阅读进度、FSRS 状态和笔记索引。
- 网站对象存储：在 OneDrive 未连接或同步失败时暂存上传文件和 Markdown。
- 大型音视频：优先保存在有稳定在线播放能力的对象存储或网盘，网站只保存索引和链接。

OneDrive、百度网盘或其它外部链接能否直接播放，取决于分享权限和服务商策略。把它们当作“资料入口/下载链接”最稳妥；需要稳定在线播放时应迁移到对象存储。

## 技术结构

- 前端与 API：vinext / React
- 结构化数据：D1（资源、进度、计划和文件记录）
- 主要资料文件：个人版 OneDrive 应用专用文件夹
- 临时文件与同步缓冲：R2
- 身份：托管平台的 ChatGPT 私人访问
- 版本管理：GitHub 仓库 `qin4420-rgb/English-learner`

网站不是纯静态页面，因此 GitHub Pages 不能单独承担正式运行。GitHub 用于保存代码与版本；正式网站由支持私人登录、数据库和文件存储的平台运行。

## 本地开发

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
npm run lint
npm test
```

数据库结构调整后运行：

```bash
npm run db:generate
```

持久化能力在 `.openai/hosting.json` 中声明；数据库迁移位于 `drizzle/`。

运行所需的 OneDrive、DeepSeek 和令牌加密配置必须放在托管平台的安全环境变量中。仓库只提供空白的 `.env.example`，不要把真实密钥提交到 GitHub。
